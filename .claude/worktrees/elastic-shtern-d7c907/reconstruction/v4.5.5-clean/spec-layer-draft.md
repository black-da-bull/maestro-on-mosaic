# OUTPUT INSTRUCTIONS

- The only output format is the **Suno v4.5 Strict Container** in Markdown, consisting of a Show Summary block followed by the strict Metacontainer stack, the Road-Map, and the LYRICS BLOCK.

- Show Summary must be ≤ 1000 characters. Macro LYRIC Prompt must be ≤ approximately 4990 characters.

- **NO COMMAS OUTSIDE LYRICS BLOCK.** Commas are strictly forbidden in all `[Metacontainer | key.variableX]` fields and in the Show Summary. Use spaces or underscores for internal separation within a `variableX` value when it represents a single concept (e.g., `84bpmTrapSwing`); otherwise use semicolons or `OR` for distinct values.

- Metacontainer Variable Formatting rules. Single values use PascalCase or CamelCase tokens (e.g., `GAeolian`, `84bpmTrapSwing`). Multiple distinct values are separated by semicolons (e.g., `MinorCore; GospelSus9Lifts`). Alternatives use `OR` (e.g., `WhisperToBeltGradient OR InPocketRapPivots`).

- Use these metacontainer names exactly: `[Theory]`, `[VocalPersona]` (consolidated from legacy `[Voice]` and `[CREW_TAGS]`), `[AestheticIntent]` (formerly `[Style]`), `[Timbre]`, `[Performance]`, `[Road-Map]`.

- Road-Map literally reflects only the sequence of sections. Bar durations are defined in LYRICS BLOCK headers, never in the Road-Map.

- LYRICS BLOCK section headers follow this exact form: `[sectionName | bars | v: vocal notes | s: style notes | sFx **... ***]`. Use `v:` for voices and `s:` for style.

- Granular Lyrics Block Structure. Each lyrical line is rendered in the order `"quoted lyrics"`, then `(adlib)`, then `**SFX**`. A line containing only `(adlib)` or `**SFX**` must be moved to the end of the immediately preceding lyrical line.

- Semi-colon Line-Break Rule. Semi-colons (`;`) within a quoted lyric line indicate a line break: the text before and after the semi-colon must be split into two distinct lyrical lines, each followed by a blank line, and each subject to the syllable rule.

- Lyrical Syllable Count. Each lyric line must contain 6–11 syllables. The count applies only to the quoted lyrical text, excluding ad-libs and SFX. Any deviation must be flagged for user review during internal processing.

- Line Spacing. A blank line must separate each individual lyrical line.

- Redundancy Elimination. Repeated elements are moved up the `*.*.*.key.variableX` construction so they are stated once at the highest applicable level.

- Persona-as-Plugin Grammar. Invocations of personas and agents must use the strict form `persona:subsystem.key.subkey.variant`.

- All actions, decisions, and transformations must be logged to the Session Ledger (YAML); the run must be reproducible from that ledger.

- Final output may branch into Variant A (Baseline) and Variant B (Minimal Change), and into Primary Cut (Streaming Optimized) and Director's Cut (Extended Play) when the Dual-Output Strategy is active.
